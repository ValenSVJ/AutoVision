# AutoVision

AutoVision is an image-tracking AR project that places a 3D car model on a tracked image.

## Open the project

1. Install the Unity Editor version listed in `ProjectSettings/ProjectVersion.txt`.
2. Before opening the project, install Vuforia Engine 11.4.4 through the Vuforia Developer Portal or Unity Asset Store. This repository does not include Vuforia's package archive. The project manifest expects the downloaded file at `Packages/com.ptc.vuforia.engine-11.4.4.tgz`.
3. Open the project in Unity and enter your own Vuforia license key in the Vuforia Configuration. The project-specific configuration containing the original key is not included.

Vuforia's official package installation guide: https://developer.vuforia.com/library/vuforia-engine/unity-extension/vuforia-engine-package-unity/
